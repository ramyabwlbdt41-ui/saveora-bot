# SAVEORA ⚡️ — بوت تلغرام لتحميل الفيديو

أرسل رابط فيديو من أي موقع ← تستقبل الملف مباشرة على تلغرام.
يعمل على `yt-dlp` (يدعم ~1800 موقع) و`ffmpeg` لدمج الصوت مع الصورة.

**التكلفة: 0$** — لا APIs مدفوعة، لا دومين، استضافة مجانية دائمة على Oracle Cloud.

## الواجهة

- **ترحيب شخصي** باسم كل مستخدم (`first_name` من تلغرام).
- **إرسال فوري**: ترسل الرابط ← يصل الفيديو مباشرة، بلا قائمة جودات.
- **جودة 720p افتراضياً**: الأسرع والأخف (يُفضل ملف واحد بلا دمج)، وتقدر تطلب 1080p بزر.
- **زر ⬆️ نسخة 1080p**: يظهر بعد كل فيديو 720، ويعيد الجلب بالجودة الأعلى ويرسله.
- **أزرار بعد كل فيديو**:
  - 🎵 **إزالة الموسيقى** — يفصل الكلام/الغناء عن الموسيقى والإيقاع ويعيد الفيديو بصوت بشري فقط.
  - 🎤 **الكلام فقط** — الصوت المفصول كملف MP3.
  - 🔇 **بدون صوت** — يحذف المسار الصوتي بالكامل.
- **شريط تقدّم حقيقي**: `████████░░░░ 64%` + السرعة + الوقت المتبقي.
- **أزرار لوحة**: 📖 طريقة الاستخدام · 📊 الحالة.

اصطلاح التسمية/الوصف/الأوامر في تلغرام يُضبط مرة واحدة بـ:

```powershell
python setup_bot.py
```

## التشغيل السريع على جهازك (5 دقائق)

### 1. احصل على توكن البوت
1. افتح تلغرام ← ابحث عن **@BotFather**.
2. أرسل `/newbot` ← اختر اسماً ← اختر يوزر ينتهي بـ `bot`.
3. انسخ التوكن (شكله `123456789:AAE...`).

### 2. ثبّت FFmpeg
```powershell
winget install Gyan.FFmpeg
```
ثم **أغلق PowerShell وافتحه من جديد** (حتى يتحدّث PATH).

### 3. شغّل
```powershell
cd tg-video-bot
powershell -NoProfile -ExecutionPolicy Bypass -File run.ps1
```
السكربت ينشئ `venv`، يثبّت المكتبات، يفتح `.env` لتضع التوكن، ثم يشغّل البوت.

### 4. جرّبه
- أرسل `/start` للبوت.
- أرسل `/id` وانسخ رقمك ← ضعه في `ALLOWED_USER_IDS` داخل `.env` (اختياري لكن مستحسن).
- الصق أي رابط ← اختر الجودة ← استلم الملف.

> البوت يعمل فقط ما دامت النافذة مفتوحة. للتشغيل الدائم → القسم التالي.

## التشغيل الدائم مجاناً على Oracle Cloud

Oracle تمنح **Always Free**: 4 أنوية ARM + 24GB رام + 200GB تخزين — مجاناً بلا حد زمني.

### 1. أنشئ السيرفر
1. <https://cloud.oracle.com> ← سجّل (تحتاج بطاقة للتحقق فقط، لا يُخصم منها).
2. اختر **Home Region** قريباً منك (مثلاً Frankfurt).
3. **Compute → Instances → Create instance**
   - Image: **Ubuntu 24.04**
   - Shape: **VM.Standard.A1.Flex** (Ampere/ARM) ← 2 OCPU و12GB تكفي
   - أضف مفتاح SSH (حمّل الملف الخاص)
4. بعد الإنشاء انسخ **Public IP**.

> إذا ظهر «Out of capacity» للـ ARM، جرّب مرة أخرى بعد ساعات أو اختر `VM.Standard.E2.1.Micro` (AMD، أضعف لكن متاح دائماً).

### 2. ارفع الملفات
```bash
scp -i your-key.pem -r tg-video-bot ubuntu@<IP>:/home/ubuntu/
ssh -i your-key.pem ubuntu@<IP>
```

### 3. ثبّت
```bash
cd /home/ubuntu/tg-video-bot
sudo bash install.sh
sudo nano /opt/tg-video-bot/.env      # ضع BOT_TOKEN
sudo systemctl restart tg-video-bot
```

### 4. تحقق
```bash
systemctl status tg-video-bot
journalctl -u tg-video-bot -f
```
سترى `البوت يعمل…` — أرسل رابطاً في تلغرام وسيشتغل.

السكربت يثبّت خدمة `systemd` تُعيد التشغيل تلقائياً عند أي تعطّل أو إعادة إقلاع.

## الحدود والحقائق

| القيد | السبب | الحل |
|---|---|---|
| حجم أقصى **50 MB** | حد Telegram Bot API للرفع | جودة أقل، أو 🎵 صوت فقط |
| مدة **60 دقيقة** | إعداد قابل للتغيير في `.env` | عدّل `MAX_DURATION_MIN` |
| موقع لا يعمل فجأة | الموقع غيّر حمايته | `pip install -U yt-dlp` ثم إعادة تشغيل |
| «Sign in to confirm you're not a bot» من يوتيوب | حماية ضد السيرفرات | مرّر كوكيز متصفحك (انظر أدناه) |
| نتفليكس/شاهد | DRM حقيقي | غير ممكن — لا توجد طريقة قانونية |

### ملفات الكوكيز (لليوتيوب عندما يطلب تحقق)
صدّر كوكيز متصفحك بصيغة `cookies.txt` (إضافة *Get cookies.txt LOCALLY*)، ضعها في
`/opt/tg-video-bot/cookies.txt`، وأضف داخل `build_ydl_opts`:

```python
opts["cookiefile"] = "/opt/tg-video-bot/cookies.txt"
```

> استخدم حساباً ثانوياً، ولا ترفع ملف الكوكيز على GitHub أبداً.

### رفع ملفات أكبر من 50MB (متقدّم)
شغّل **Local Bot API Server** من تلغرام على نفس السيرفر ← الحد يرتفع إلى **2GB**.
يحتاج `api_id`/`api_hash` من <https://my.telegram.org> وتعديل اتصال المكتبة إلى
`base_url="http://localhost:8081/bot"`. هذا الخيار يستهلك ذاكرة أكثر.

## بنية الملفات

```

├── sep_worker.py          عامل فصل الموسيقى (يعمل في venv312)
├── install_sep.ps1        إنشاء بيئة 3.12 وتثبيت audio-separator
├── setup_bot.py           ضبط الاسم/الوصف/الأوامر عبر Bot API
├── requirements.txt       python-telegram-bot + yt-dlp + dotenv
├── .env.example           قالب الإعدادات
├── run.ps1                تشغيل على Windows
├── install.sh             تثبيت على Ubuntu + خدمة systemd
├── models/                نموذج ONNX (يُنزَّل تلقائياً)
└── _cache/                ملفات محفوظة 45 دقيقة لعمل الأزرار
```

## كيف يعمل داخلياً

1. رسالة تحتوي رابطاً ← يُستخرج بـ regex.
2. **فحص سريع** للرابط (`extract_info` بلا تحميل) لمعرفة الجودات والأحجام المتاحة.
3. **اختيار تلقائي**: أعلى جودة يُتوقع أن تمرّ تحت سقف 50 MB — بلا أزرار ولا أسئلة.
4. `yt-dlp` يعمل في **thread** منفصل حتى لا تتجمّد حلقة الأحداث، وشريط التقدّم يتحدّث كل 2.5 ثانية.
5. إن كان الناتج أكبر من الحد ← ينزل جودة واحدة تلقائياً ويعيد المحاولة، ثم 🎵 صوت.
6. الإرسال `send_video`، وإن رفض تلغرام الصيغة يرسلها `send_document`.
7. مجلد مؤقت لكل طلب يُحذف في `finally` — لا يتراكم شيء على القرص.
8. `SEMAPHORE` يمنع أكثر من تحميل واحد في نفس الوقت.

## ffmpeg (مطلوب للدمج وإزالة الموسيقى)

بدونه يعمل البوت لكنه يختار **ملفاً واحداً جاهزاً** (غالباً 360p–720p) لأن دمج
الصوت مع الصورة يحتاج ffmpeg، وأزرار تعديل الصوت لا تعمل.

```powershell
winget install Gyan.FFmpeg
```
أو `pip install imageio-ffmpeg` (البوت ينسخ الملف تلقائياً إلى `ffmpeg/ffmpeg.exe`)،
أو ضع `ffmpeg.exe` في مجلد `tg-video-bot/ffmpeg/`، أو اضبط `FFMPEG_LOCATION` في `.env`.
يظهر حالته في `/stats`.

## إزالة الموسيقى (فصل المصادر)

تعتمد على **AI source separation** وليس على إلغاء القناة الوسطى، لذلك يحذف الموسيقى
والإيقاع ويُبقي الكلام وحده:

- المحرّك: `audio-separator` + نموذج ONNX `Kim_Vocal_2.onnx` (يعمل على المعالج).
- يحتاج **Python 3.12** (حزم ML لا تدعم 3.14 بعد) ← البيئة معزولة في `venv312`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_sep.ps1
```

- العامل `sep_worker.py` يُستدعى كعملية منفصلة، والنموذج يُنزَّل مرة واحدة إلى `models/`.
- الحدود الواقعية: دقة عالية في الكلام العادي، لكن الغناء المختلط بالموسيقى قد يبقى
  فيه أثر، والصوت قد يبدو «أنحف» قليلاً. المدة: ~دقيقة معالجة لكل دقيقة فيديو.


## استكشاف الأخطاء

| الرسالة | المعنى |
|---|---|
| `BOT_TOKEN غير موجود` | لم تنشئ `.env` أو نسيت وضع التوكن |
| `ffmpeg not found` | ثبّت ffmpeg وأعد فتح الطرفية |
| `Unsupported URL` | الموقع غير مدعوم — جرّب تحديث yt-dlp |
| `File is larger than 50 MB` | اختر جودة أقل |
| البوت صامت | `journalctl -u tg-video-bot -f` لرؤية الخطأ |
